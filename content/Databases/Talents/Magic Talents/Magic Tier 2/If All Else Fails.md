**Tier:** 2
**Activation:** Passive
**Ranked:** Yes

When purchasing a rank in this [[Talents|Talent]], pick one [[Modifiers|Modifier]] used in [[Spell Creation]]. That Modifier now costs -1 Magic Point, to a minimum of 2. If a Modifier has a cost of 2 by default, add an additional free rank whenever it is added to a Spell. If a Modifier has a cost of 1 by default, add three additional free ranks whenever it is added to a Spell. 

Each additional rank in If All Else Fails allows a [[Character]] to add another Modifier discount, including to the same Modifier, if the cost of the Modifier is not already 2 or below.

**If All Else Fails** cannot be used on [[Accurate (Modifier)|Accurate]], [[Increase Power (Modifier)|Increase Power]], or [[Increase Range (Modifier)|Increase Range]].
