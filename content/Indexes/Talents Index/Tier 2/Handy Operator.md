**Tier:** 2
**Activation:** Active (Incidental)
**Ranked:** No

Whenever making a [[Skill Checks|Skill Check]] (including [[Attack Check|Attack Checks]]), may suffer 3 [[Strain]] to instead use the [[Operating]] [[Skills|Skill]] so long as the [[Character]] with this [[Talents|Talent]] is using an [[Items|Item]], tool, object, or machine which is to a certain extent meant to facilitate, allow, or assist in the task they are currently attempting. If the Skill that would regularly be used is [[Force]], [[Brawl]], [[Melee-Light]] or [[Melee-Heavy]], may not use this Talent to change the Skill. Using a [[Hyrulean Crossbow|Crossbow]], [[Cannon]], [[Grappling Hook]], etc, or a tool found in a [[Toolkit]], for its intended purpose or a clever use in which its use would naturally help, would allow the use of Operator’s Expertise.
