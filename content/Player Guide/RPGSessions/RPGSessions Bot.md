The [[RPGSessions]] Discord bot is used for [[Echoes of the Departed|Echoes of the Departed]] due to its great functionality and integration with the [[RPGSessions]] website.

![](https://i.imgur.com/5bQcsHL.png)

To invite the bot, [follow this link.](https://discord.com/oauth2/authorize?client_id=534606682928578572&permissions=274878171136&scope=applications.commands%20bot)

The following is a basic overview of commands used in the RPGSessions bot. To view documentation directly from RPGSessions, [visit this page](https://rpgsessions.com/docs/discord-bot). While many of these options are more intuitive to do on the [[Game Table|Game Table]], some things—such as rolling [[Narrative Dice|Dice]]—can be more convenient using the bot.

You can see a variety of different options from the bot by going to a channel where it is present and typing the prefix of “/”. It allows you to roll Dice, edit [[Character|Characters]]’ [[Wounds]] or [[Strain]], add [[Critical Injury|Critical Injuries]] and use [[Sacred Points|Sacred Points]], etc.

I encourage you to mess around and see the documentation page to figure out what to do! Feel free to roll some dice while messing around. 

When rolling, remember Dice or symbols are usually represented by a single letter, such as [[Ability Dice]] being known as “A” for Ability (if you are using the Game Dice Naming Scheme) or “G” for Green (if you are using the Color Dice Naming Scheme which is more common). You can look at the documentation for the full list of Dice and their accompanying symbolizing letter.

### Changing Dice Naming Scheme
You may want to change the Dice naming scheme; this determines whether, to roll a [[Difficulty Dice|Difficulty die]] on Discord, you would type “p” for Purple or “d” for Difficulty. First, navigate to your profile from the RPGSessions website.

![](https://i.imgur.com/LM8Bd7Y.png)

Once there, hit the “Dice Input Style” button in the user settings category.

![](https://i.imgur.com/VIGpTkX.png)

Select ‘Color’ or ‘Game’ from the drop-down menu depending on which one you want.
