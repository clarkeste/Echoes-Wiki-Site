*[Access the Game Table here!](https://app.rpgsessions.com/game/5c170cf6-ce75-42ef-88c1-1227ebb4d6e6/table)*

The Game Table is the center of the game, on the [[RPGSessions]] website. While most of its functions can be achieved using the [[RPGSessions Bot]], using the Game Table offers both integration with the server and an intuitive GUI.

To find the Game Table, look at the tabs at the top-right of the website. Select ‘Games’.

![](https://i.imgur.com/11wI82U.png)

After changing to the Game Tab, the currently active games will appear. If you are in a Discord server that is linked to a currently running Game Table, it should automatically appear.

Select ‘Open Game’ to enter the Game Table.

![](https://i.imgur.com/9DqrPOe.png)

Now, you’re inside the Game Table! You can do various actions, such as rolling [[Initiative]], rolling for [[Sacred Points]], rolling [[Skill Checks]], or viewing your [[Character Sheet]].

### What Can I Do In The Game Table?
A whole bunch of very useful things. Firstly, anything that can be done with the [[RPGSessions Bot]] can be done in the Game Table. I suggest you look around a bit first and mess around, and figure out what you can do here.

In addition to easy access to your [[Character Sheet]] for editing once added, as well as being able to see the sheets of other Characters and adversaries, you can easily see the [[Initiative]], [[Sacred Points|Sacred Point]] count, and roll history.

You can also click on a [[Dice Pool]] either next to a [[Weapons|Weapon]] or [[Skills|Skill]] name on your Character Sheet while it is open in the Game Table to immediately open the rolling modal. Potentially relevant automated [[Talents]] will be automatically applied, or if it needs your decision to be used, may appear as a button you can press to automatically apply the benefits and costs to your Character. Additionally, if you try to roll an [[Attack Check]] by clicking on the Dice Pool next to a Weapon, it will allow you pick the target. This auto-determines the [[Difficulty]], keeping in mind modifiers such as [[Defense]], and also allows the targeted enemy to use relevant defensive [[Talents]] as part of the same Check.
