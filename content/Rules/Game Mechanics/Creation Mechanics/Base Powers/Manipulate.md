Manipulate allows you to pick up and move objects/people with [[Silhouette]] limitations. 

Default [[Range Bands|Range]] is [[Short Range|Short]], and targets can only pulled as high as Short Range off the ground. [[Modifiers]] that increase the Range will also increase how high they can be moved, to a maximum of [[Long Range|Long]]. 

The Range of the Spell also determines how far away from the Spellcaster an object or person can be moved using Manipulate.

- Silhouette 0: [[Difficulty|1p]]
- Silhouette 1: [[Difficulty|2p]]
- Silhouette 2: [[Difficulty|3p]]
- Silhouette 3: [[Difficulty|4p]]
- Silhouette 4: [[Difficulty|5p]]

Anything bigger is often impossible. 

If the target of Manipulate is a minor NPC or an object, [[Difficulty]] is determined by Silhouette using the Difficulties listed above.

If grabbing an important [[Adversary|Rival]] or [[Adversary|Nemesis]], as determined by the [[The GM|GM]], [[Difficulty]] is determined by the target’s [[Discipline]] or [[Resilience]], whichever is higher, in an [[Opposed Check]]. If this would result in the Manipulate check being easier, then the default Silhouette Difficulty is used instead.

The Caster must spend a [[Maneuvers|Maneuver]] every turn to keep the targeted being in their Grip. This Maneuver can move the target, or simply keep them in place. When a character is under the effect of a Manipulate Spell, the target can still use [[Actions]] and Maneuvers, but cannot use the Move Maneuver, thereby making them stuck in place.

Picked up [[Items]] or [[Character|Characters]] suffer damage if Hurled (thrown harshly), or if they have something else Hurled at them. The [[Damage]] is equal to their silhouette x10. Silhouette 0 deals 5 Damage. When attacking with a Hurled item, it functionally has a [[Critical Rating]] of 4, but if the object is sharper, [[The GM]] may rule otherwise.

Hurling requires an [[Actions|Action]] from the Spellcaster using Manipulate, and can only be done on a target already under the influence of Manipulate. The Difficulty of throwing like this is determined by Range, using the same rules as regular [[Attack Check|Attack Checks]].

If, during the initial check to Grip a target using Manipulate, the Spellcaster gained 2 [[Advantage]] or a [[Triumph]], they may immediately Hurl the target as if that Check was an Attack Check.
